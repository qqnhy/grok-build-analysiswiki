# 阅读路线图

按问题选择路线，不必从第 1 章线性读到第 20 章：

| 目标 | 推荐顺序 | 预计收获 |
| --- | --- | --- |
| 快速理解运行链路 | 01 → 02 → 03 → 04 → 05 | 从 CLI 到一次模型 turn 的完整调用图 |
| 审计本地数据和网络出口 | 06 → 07 → 09 → 10 → 18 | session、memory、sandbox 和遥测边界 |
| 扩展 agent 能力 | 04 → 08 → 11 → 19 → 20 | tool、MCP、plugin、multi-agent 和 prompt |
| 研究宿主工程实现 | 12 → 13 → 14 → 15 → 16 | TUI、VCS、测试、证据与 crate 地图 |

## 建议的阅读节奏

1. 先浏览[架构快览](architecture-overview.md)和[术语表](glossary.md)。
2. 每读一章，至少打开一个源码证据链接；行号是导航提示，源码演进后以符号名为准。
3. 看到“推断”“可能”“需要验证”等表述时，回到对应测试、feature gate 或服务端边界，
   不要把静态代码存在误读为默认发行行为。
4. 最后用[总结与可验证结论](../../../analysis/17-summary.md)和[代码证据索引](../../../analysis/15-code-evidence-index.md)
   做反向复盘。
